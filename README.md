# CBP Analysis

_powered by the dbt Fusion engine_

Welcome! This is a portfolio project prototyping an analysis of CBP Hedis metrics by provider, provider organization and payer.  The daya is from Synthea (https://synthetichealth.github.io/synthea/)

To get started:
1. Set up your database connection in `~/.dbt/profiles.yml`. If you got here by running `dbt init`, you should already be good to go.
2. Run `dbt build`. That's it!
